Spreadsheet Merge

Add a new spreadsheet into a master spreadsheet: fill in blanks, update with more-detailed values, add new rows and columns. Your master file is never changed.
How it works: rows are matched between the two files using the key column you name (for example an ID or accession number). Where the master is blank, the new sheet fills it in. Where both have a value but they differ, the longer, more detailed value wins. New records and new columns from the second sheet are added. Nothing is overwritten silently — you get a full change report.
